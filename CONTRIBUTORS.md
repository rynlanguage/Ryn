## Keeping this list current

The table is maintained by hand and must match the history. After a release or a large merge,
regenerate the counts and compare:

```sh
git shortlog -sne --all
```

Add a row only for a real author in the log, and keep the GitHub link for authors whose commits carry
a GitHub noreply address or a matching profile. Do not add tooling accounts, bots, or AI assistants
unless they appear as commit authors on their own work.
